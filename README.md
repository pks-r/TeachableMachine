## نبذة عن المشروع

**تعرّف على الفاكهة** موقع ويب بسيط يستخدم نموذج ذكاء اصطناعي مدرّب عبر [Google Teachable Machine](https://teachablemachine.withgoogle.com/) للتعرف على نوع الفاكهة أو العنصر الموجود في الصورة.

يرفع المستخدم صورة من جهازه، فيعرض الموقع نتيجة التصنيف على شكل نسبة ثقة لكل فئة. يعمل المشروع بالكامل داخل المتصفح، ولا يحتاج إلى Backend أو Server خاص.

## تجربة المشروع

لا تحتاج إلى تحميل أي ملفات، افتح الرابط وجرّب مباشرة:

**[pks-r.github.io/TeachableMachine](https://pks-r.github.io/TeachableMachine/)**

## المميزات

- رفع صورة من الجهاز لتصنيفها
- تصنيف الصور باستخدام نموذج ذكاء اصطناعي
- عرض نسبة الاحتمال لكل فئة
- تمييز نسب كل فئة بلون خاص بها
- يعمل مباشرة داخل المتصفح بدون Backend
- واجهة عربية بسيطة (RTL)

## طريقة التشغيل محليًا

> يحتاج المشروع إلى اتصال بالإنترنت، لأن المكتبات والنموذج يُحمَّلان من الإنترنت عند فتح الصفحة.

### الطريقة الأولى: تحميل ZIP

1. افتح صفحة المستودع على GitHub.
2. اضغط **Code** ثم **Download ZIP**.
3. فك ضغط الملف.
4. افتح ملف `index.html` في المتصفح.

### الطريقة الثانية: استنساخ المستودع بـ Git

```bash
git clone https://github.com/pks-r/TeachableMachine.git
cd TeachableMachine
```

ثم افتح ملف `index.html` في المتصفح.

### الاستخدام

1. انتظر ظهور الرسالة التي تفيد بأن الموقع جاهز، وعندها يتفعّل زر **تعرّف الآن**.
2. اختر صورة من جهازك.
3. اضغط **تعرّف الآن**.
4. ستظهر قائمة بالفئات مع نسبة الاحتمال لكل منها.

## التقنيات المستخدمة

| التقنية | دورها في المشروع |
|---------|------------------|
| **HTML** | بناء هيكل الصفحة ورفع الملف وعرض النتائج |
| **CSS** | تصميم الواجهة وتنسيق البطاقة والأزرار وقائمة النتائج |
| **JavaScript** | تحميل النموذج، قراءة الصورة، وتشغيل التصنيف وعرض النتائج |
| **TensorFlow.js** | تشغيل نماذج التعلم الآلي داخل المتصفح |
| **Teachable Machine Image** | مكتبة تحميل النموذج المدرّب واستخدامه لتصنيف الصور |

## آلية عمل النموذج

1. **التحميل:** عند فتح الصفحة، يتم تحميل ملفي النموذج `model.json` و`metadata.json` من Google Teachable Machine.
2. **التفعيل:** بعد اكتمال التحميل، يتفعّل زر التعرّف.
3. **قراءة الصورة:** عند اختيار صورة والضغط على الزر، تُقرأ الصورة وتُحوَّل إلى عنصر `<img>` داخل المتصفح.
4. **التصنيف:** تُمرَّر الصورة إلى النموذج عبر `model.predict` فيُرجع احتمال كل فئة.
5. **العرض:** تُعرض النتائج كنسب مئوية في قائمة، ولكل فئة لون مختلف.
