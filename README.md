# 🍎 تعرّف على الفاكهة

موقع بسيط يتعرّف على نوع الفاكهة من صورة ترفعها، باستخدام نموذج ذكاء اصطناعي تم تدريبه على [Teachable Machine](https://teachablemachine.withgoogle.com/). يعمل كله داخل المتصفح بدون سيرفر.

🔗 **جرّبه مباشرة:** [pks-r.github.io/TeachableMachine](https://pks-r.github.io/TeachableMachine/)

## ماذا يفعل المشروع؟
- يحمّل نموذج تصنيف صور مدرّب مسبقًا
- تختار صورة من جهازك
- يعرض لك نسبة الاحتمال لكل نوع من الأنواع التالية:
  🍊 برتقال، 🍌 موز، 🥒 خيار، 🍎 تفاح

## طريقة الاستخدام

**الطريقة الأسهل:** افتح [رابط المشروع](https://pks-r.github.io/TeachableMachine/) مباشرة من المتصفح.

**أو شغّله على جهازك:**
1. حمّل المشروع (**Code ← Download ZIP**) وفك الضغط
2. افتح ملف `index.html` في المتصفح
3. انتظر حتى يتحمّل النموذج (يظهر النص "يمكنك الآن رفع صورة")
4. اختر صورة فاكهة واضغط **تعرّف الآن**
5. ستظهر النتائج بنسب مئوية لكل نوع

> يحتاج المشروع اتصالًا بالإنترنت لأن المكتبات والنموذج يُحمَّلان من الإنترنت.

## التقنيات المستخدمة
- HTML و CSS و JavaScript

- [Teachable Machine Image](https://github.com/googlecreativelab/teachablemachine-community)
